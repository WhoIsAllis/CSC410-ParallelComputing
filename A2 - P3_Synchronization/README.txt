CSC 410 - Assignment 2 Part 3: Synchronization of Threads
==========================================================

Requirements
------------

- GCC with C11 and pthread support
- Windows PowerShell with WSL, or another Linux terminal

Run all commands from the "A2 - P3_Synchronization" directory.


Task 1 
--------------------------------------

Build:

wsl gcc -std=c11 -Wall -Wextra -Wpedantic -pthread neuromancer.c -o neuromancer

Run:

wsl ./neuromancer


Task 2 
-----------------------------------------

Build:

wsl gcc -std=c11 -Wall -Wextra -Wpedantic -pthread average.c -o average

Run:

wsl ./average
